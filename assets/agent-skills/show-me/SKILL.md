# Show me

Choose the smallest useful view: pseudocode for an algorithm, a shallow file or
component tree for ownership, a call tree for control flow, or Mermaid for
interactions and state transitions. Use a diff when the important information is
the change itself.

For a dense visual UI or comparison, create one focused responsive HTML artifact
or use the harness's visualization capability, then open or display it using the
available browser or artifact tools. Keep the adjacent prose short and include
only the names, states, and boundaries needed to answer the current question.
