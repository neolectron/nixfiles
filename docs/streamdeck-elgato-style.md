# Elgato-style mixer cards — 13 October 2026

Runtime follow-up: the package now runs `.ts` directly in Node 24, with `.ts`
relative imports, `noEmit`, no barrel and no build step. Historical build checks
below describe the renderer delivery before that change. The current commands
and direct module imports are documented in the package README.
Platform follow-up: direct Node built-in imports were replaced in both sources
and tests. Asset paths use Effect `Path` with `NodePath.layer`, and test filesystem
and subprocess operations use scoped Effect services. The same 45 Stream Deck
cases now run through `@effect/vitest`; the production CLI still runs `.ts`
directly with Node and has no build step.

The user supplied two Elgato LCD photos and explicitly chose **semicircular
gauges like the photos**. Implemented in the existing isolated task-11 clone
and branch, after the volume-boost commit `8103cf2d`.

## Delivered

- Rounded charcoal cards with tonal depth and dark gutters.
- Mixed-case app/output names, familiar source icons and antialiased typography.
- A graduated semicircle, shaded knob face and pale pointer at lower left.
- Large right-aligned volume with smaller unit/state underneath.
- Green nominal arc, with yellow → orange → red boost between 100% and 200%.
- Preserved volume when muted; grey gauge, crossed speaker and Muted label.
- Offline, mixed-mute, empty app and missing-output states using the same layout.
- Font-measured ellipsis instead of cutting every title at twelve characters.

`src/mixer-display.ts` owns the display; `src/svg.ts` owns the optional native
renderer boundary. Effect handles native calls, failures, asynchronous rendering,
file reads and bounded font-measurement caching. The renderer has no audio or HID
access. The live mixer reuses one display instance and its cache. resvg 2.6.2 is
pinned only in Stream Deck; no install scripts were enabled. Two bundled open
Liberation Sans 2.1.5 fonts give Arial-compatible lettering. The exact Elgato font
is not asserted. Three pinned Simple Icons 15.0.0 silhouettes and the font/icon
licenses are retained under `assets/` with source documentation.

The CLI uses Effect `Command`/`Flag` for an inert preview command:

```sh
pnpm streamdeck preview --output /tmp/mixer.png
```

The [preview PNG](streamdeck-elgato-style/preview.png) is generated by that command
using the production renderer and illustrative fixture values. It shows the real
1200px strip geometry in three rows, including 168px edge cards and 216px interior
cards, long accented names, zero gain, nominal gain, boost, mute, mixed, offline,
empty and missing-output states. It is a programmatic renderer preview, not a
photograph or a screenshot of the physical device. No raster generation model
was used. Durable layout/type/color decisions are recorded in the package's
`DESIGN.md` and its Impeccable sidecar.

## Master diagnostic: desktop shell clamps the output

Manuel confirmed that rotating the rightmost dial left lowers its volume. The
[diagnostic snapshot](streamdeck-elgato-style/master-diagnostic.log) corroborates
100 → 98 → 80 → 78 → 66 and then 74 → 90 → 98. A subsequent +24 request returns
100 rather than 122; further positive requests remain at 100. Target name and
serial consistently match the freshly read sink (`headphones_input`, serial 51),
so the stale-output guard does not discard these requests.

The active Quickshell process (PID 2471 when inspected) has `QS_CONFIG_PATH` set to
`/nix/store/w30j5s3b5g57xi2j21f0ikps0hg0mifq-noctalia-shell-2026-05-03_f0469d2/share/noctalia-shell`.
Read-only inspection of that exact installation's `Services/Media/AudioService.qml`
finds a maximum of 1.0 by default, or 1.5 with `volumeOverdrive` (line 27).
Its `onVolumeChanged` handler actively rewrites an externally increased output
to that maximum (lines 932–939). `Commons/Settings.qml` defaults the option to
false (line 717); the local settings JSON's audio object contains only
`spectrumFrameRate: 30`, with no overdrive override. This matches the observed
100% reset. PipeWire's node Props advertise a higher range; this is not evidence
of a universal PulseAudio or PipeWire 100% limit.

The library's 200% limit remains tested, and the preview shows the full boost
palette. Enabling 200% on the live Master requires a separate desktop-shell
adjustment: Noctalia's existing overdrive switch alone only permits 150%.
No shell setting, system package, default sink, routing or microphone setting was
changed for this diagnostic. Temporary `master-debug` instrumentation was removed
before finishing, and the production mixer was restarted with the normal source.

The main checkout, preparation, NixOS/Home Manager settings, USB permissions,
microphone/capture devices, Discord configuration, keep-awake installation and
Formula remain unchanged. No push, merge, PR or project-attachment claim.
