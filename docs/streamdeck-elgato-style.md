# Elgato-style mixer cards — 13 October 2026

The user supplied two Elgato LCD photos and explicitly chose **semicircular
gauges like the photos**. Implemented in the existing isolated task-11 clone
and branch, after the volume-boost commit `8103cf2d`.

## Delivered

- Rounded charcoal cards with tonal depth and dark gutters.
- Mixed-case app/output names, familiar source icons and antialiased typography.
- A graduated semicircle, shaded knob face and pale pointer at lower left.
- Large right-aligned volume with smaller unit/state underneath.
- Green nominal arc, with yellow → orange → red boost between 100% and 200%.
- Preserved volume when muted; grey gauge, crossed speaker and Muted label.
- Offline, mixed-mute, empty app and missing-output states using the same layout.
- Font-measured ellipsis instead of cutting every title at twelve characters.

`src/mixer-display.ts` owns the display; `src/svg.ts` owns the optional native
renderer boundary. Effect handles native calls, failures, asynchronous rendering,
file reads and bounded font-measurement caching. The renderer has no audio or HID
access. The live mixer reuses one display instance and its cache. resvg 2.6.2 is
pinned only in Stream Deck; no install scripts were enabled. Two bundled open
Liberation Sans 2.1.5 fonts give Arial-compatible lettering. The exact Elgato font
is not asserted. Three pinned Simple Icons 15.0.0 silhouettes and the font/icon
licenses are retained under `assets/` with source documentation.

The CLI uses Effect `Command`/`Flag` for an inert preview command:

```sh
pnpm streamdeck preview --output /tmp/mixer.png
```

The [preview PNG](streamdeck-elgato-style/preview.png) is generated by that command
using the production renderer and illustrative fixture values. It shows the real
1200px strip geometry in three rows, including 168px edge cards and 216px interior
cards, long accented names, zero gain, nominal gain, boost, mute, mixed, offline,
empty and missing-output states. It is a programmatic renderer preview, not a
photograph or a screenshot of the physical device. No raster generation model
was used. Durable layout/type/color decisions are recorded in the package's
`DESIGN.md` and its Impeccable sidecar.
